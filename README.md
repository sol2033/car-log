# 🚗 Car Log — Журнал обслуживания автомобиля

**Car Log** — нативное Android-приложение (offline-first) для комплексного учёта всех событий и
расходов, связанных с владением одним или несколькими автомобилями: запчасти, ТО/ремонты/тюнинг,
ДТП, расходники, заправки, документы, штрафы и прочие траты. Поверх данных строится подробная
статистика.
Все данные хранятся **локально** (Room/SQLite + фото во внутреннем хранилище); есть опциональное
облачное резервное копирование на **Яндекс.Диск** и локальный экспорт/импорт.

## ✨ Возможности

- **🚙 Несколько автомобилей** — все записи привязаны к конкретному авто; удаление машины
  каскадно удаляет её данные.
- **🔧 Запчасти** — установленные детали, отслеживание ресурса по пробегу, отметка «сломана» с
  автоматическим расчётом пройденного пробега, фильтры, фото. Мелочь можно скрыть из списка,
  сохранив её стоимость в событии.
- **⚙️ Обслуживание: ТО / ремонт / тюнинг** — одно событие может быть всем сразу: тип выводится
  из содержимого, а не выбирается руками. Расходники и запчасти в одной записи, работы списком
  или общей суммой, гарантийный ремонт, сервисные центры, вложения (фото и PDF).
- **🚨 ДТП** — роль «виновник / пострадавший», страховые выплаты (ОСАГО, КАСКО, от виновника),
  компенсация пострадавшему, серьёзность повреждений, отдельное поле под протокол, фото и PDF.
  В расходы идёт то, что реально ушло из кармана: ремонт и компенсация минус полученные выплаты.
- **🧴 Расходники** — категории с настраиваемыми интервалами замены по пробегу и по времени,
  «светофор» состояния (норма / предупреждение / критично), история и статистика замен.
  Расход моторного масла: доливы и падение уровня к замене, л/1000 км по каждому маслу.
  Активной в категории всегда остаётся самая свежая установка, даже если запись завели задним числом.
- **⛽ Заправки** — бензин/дизель/газ (пропан-метан)/электро, средний расход по всем заправкам
  (газ и бензин у машины с ГБО — отдельно), пробег на полном баке по объёму бака.
- **💸 Прочие расходы** — мойка, аксессуары, автозвук, детейлинг, диски/шины и др. с категориями и заметками.
- **📑 Документы** — ОСАГО, КАСКО, транспортный налог (напоминание о следующем начислении) и
  свои типы: «светофор» по сроку действия, продление с историей цен, учёт в статистике
  («Страховка и налоги»).
- **🚔 Штрафы и платные дороги** — постановления со сроком льготной оплаты: «светофор» следит
  за скидкой, а не за долгом. В расходы идёт только фактически уплаченное, отметить оплату можно
  прямо из списка. На второй вкладке — проезды по платным дорогам с итогами по месяцам.
- **📊 Статистика** — 5 вкладок (Общая / Топливо / Ремонты / Расходы / Расходники): графики по
  периодам, круговые диаграммы распределения, тренды расхода, фильтры по периоду и пробегу,
  исключение ДТП. Графики на **Vico** с компактными осями и легендами.
- **🩺 Проверка данных** — находит расхождения между записями (запчасть без события, разошедшиеся
  суммы, сбившийся отсчёт замены расходника) и чинит их точечно, по нажатию пользователя.
- **💾 Резервное копирование** — облачный бэкап на **Яндекс.Диск** (авто-бэкап через WorkManager,
  инкрементальная выгрузка медиа) и локальный экспорт/импорт ZIP-архива (БД + фото + документы).
  Свои сбои приложение пишет в журнал на экране **Диагностика**.
- **🎨 Интерфейс** — Material 3, тёмная/светлая/системная тема, локализация **ru/en**, валюты
  ₽ RUB · $ USD · € EUR · ₸ KZT · Br BYN, плавные анимации навигации.

## 🆕 Что нового в 1.4.0

- **Средний расход видно сразу** — «полный бак» отмечать больше не нужно, расход считается
  по всем заправкам; у машины с ГБО газ и бензин отдельно, метан — в м³.
- **Пробег на баке** — по объёму бака (батареи, газового баллона) из карточки автомобиля.
- **Расход масла** — доливы кнопкой «+ Долить» на плитке масла и падение уровня при замене;
  расход в л/1000 км по каждому маслу и в среднем. Отключается в настройках.
- **Платные дороги** — раздел «Штрафы» стал «Штрафы, платные дороги».
- **Подсказки названий** сервисов и заправок, адрес сервиса подставляется сам; объём
  жидкостей берётся из прошлой замены.
- **Удаление ТО и расходников** предлагает вернуть предыдущий расходник, если категория
  осталась бы пустой.

## 📱 Установка готового APK

> Для тех, кто просто хочет пользоваться приложением.

1. Скачайте `app-release.apk` со страницы [Releases](../../releases).
2. В настройках Android разрешите установку из неизвестных источников (для браузера/файлового менеджера).
3. Откройте скачанный файл и нажмите **Установить**.

Минимальная версия — **Android 10 (API 29)**.

## 🧑‍💻 Сборка из исходников

### Требования
- **Android Studio** Hedgehog (2023.1.1) или новее
- **JDK 17** (подойдёт и 21)
- **Android SDK** (API 34)
- Gradle 8.5 — поставляется с проектом через wrapper

> ⚠️ Gradle 8.5 поддерживает JDK **не новее 21**. На более свежей Java сборка падает ещё
> на чтении build-скриптов с невразумительным `What went wrong: <номер версии>` — это Kotlin
> не может разобрать номер. Android Studio подставляет свой JBR и проблемы не видит, а вот
> сборка из терминала берёт системную Java. Если столкнулись — укажите JDK явно:
>
> ```powershell
> $env:JAVA_HOME = "C:\путь\к\jdk-21"   # PowerShell
> export JAVA_HOME=/путь/к/jdk-21          # bash
> ```

### Клонирование

```bash
git clone https://github.com/sol2033/car-log.git
cd car-log
```

Дальше можно открыть проект в Android Studio (**File → Open**, дождаться синхронизации Gradle)
либо собирать из терминала.

### Debug-сборка (быстрый старт, без подписи)

```bash
# собрать debug APK
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk

# или установить на подключённое устройство/эмулятор
./gradlew installDebug
```

> На Windows используйте `gradlew.bat` вместо `./gradlew`.

### Release-сборка (подписанный APK для магазина)

Релизная сборка подписывается ключом, описанным в `keystore.properties` в корне проекта (файл
не коммитится). Создайте его рядом с `gradlew`:

```properties
storeFile=car-log.jks
storePassword=ВАШ_ПАРОЛЬ_ХРАНИЛИЩА
keyAlias=ВАШ_АЛИАС
keyPassword=ВАШ_ПАРОЛЬ_КЛЮЧА
```

Если своего ключа нет — сгенерируйте хранилище (положите `.jks` в корень проекта):

```bash
keytool -genkeypair -v -keystore car-log.jks -keyalg RSA -keysize 2048 \
  -validity 10000 -alias car-log-key
```

Затем соберите:

```bash
./gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

> Если `keystore.properties` отсутствует, сборка пройдёт, но APK будет **неподписанным** —
> установить такой на устройство не получится.

Для публикации в Google Play вместо APK собирается App Bundle:

```bash
./gradlew bundleRelease
# → app/build/outputs/bundle/release/app-release.aab
```

### Тесты

```bash
./gradlew testDebugUnitTest         # JVM-тесты: статистика и деньги, статусы, даты,
                                    #   расход топлива, цепочки замен, проверка целостности
./gradlew connectedDebugAndroidTest # миграции БД, нужен подключённый телефон или эмулятор
```

Отчёт: `app/build/reports/tests/testDebugUnitTest/index.html`.

> Инструментальные тесты ставят debug-сборку с тем же `applicationId`, что и релизная.
> На устройстве с установленным релизом Android потребует удалить приложение — вместе
> с данными. Гоняйте их на эмуляторе или запасном устройстве.

**Новая логика добавляется вместе с тестами** — требование и таблица «что чем покрывать»
в [docs/TECHNICAL_DOCUMENTATION.md](docs/TECHNICAL_DOCUMENTATION.md), §15.1.

## 📈 Версионирование

Источник истины по версии — [app/build.gradle.kts](app/build.gradle.kts) (`versionCode` / `versionName`).
Версия также отображается на экране **Настройки → О приложении** — она подставляется из
`BuildConfig` и нигде не хардкодится.

Схема базы версионируется отдельно: любое изменение `@Entity` требует поднять `version`
в `CarLogDatabase`, добавить миграцию и зарегистрировать её. История схем — в `app/schemas/`,
она в репозитории и нужна тестам миграций.
